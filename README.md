# FiveM Solutions Server Builder

بوت Discord.js v14 بيمسح السيرفر بالكامل ويعيد بناءه من الصفر كهيكل متجر FiveM احترافي: تصنيفات وقنوات منسقة، رتب وصلاحيات، نظام تذاكر بالأزرار والنماذج والـTranscript، و8 قنوات سجلات إدارية سرية.

## المتطلبات
- Node.js 20 أو أحدث
- بوت Discord بصلاحية **Administrator** (أو على الأقل: Manage Channels, Manage Roles, Manage Messages, Manage Threads, Kick/Ban, View Audit Log, Manage Webhooks, Read Message History)
- تفعيل **Server Members Intent** و**Message Content Intent** من Developer Portal → Bot

## التشغيل

```bash
npm install
cp .env.example .env
# ضع التوكن والآيدي داخل .env
npm start
```

| المتغير | الوصف |
|---|---|
| `DISCORD_TOKEN` | توكن البوت |
| `GUILD_ID` | آيدي السيرفر المستهدف |
| `OWNER_ID` | اختياري — آيدي المالك |
| `BUILD_ON_START` | `true` = مسح وبناء عند كل تشغيل، `false` = تسجيل السجلات فقط |
| `DEBUG` | `true` = لوجز مفصلة |

## ماذا يبني

- **7 تصنيفات**: البداية، المتجر، الدعم، المجتمع، الإدارة، السجلات، التذاكر (مخفي).
- **30 قناة** بأسماء عربية وإيموجيات، منها منتدى للآراء ومنتدى لغرفة العرض.
- **5 رتب عربية** بصلاحيات متدرجة من صاحب سيرفر إلى Developer (بصلاحية Administrator).
- **نظام تذاكر**: قائمة منسدلة بأربع فئات (شراء / دعم / شراكة / استفسار) → نموذج أسئلة → قناة خاصة → ادعاء / Transcript / إغلاق مع تأكيد → تقييم بالنجوم.
- **سجلات**: دخول، خروج، رسائل (حذف/تعديل/حذف جماعي)، رتب، صوتيات، إشراف، السيرفر، تذاكر — مع تحديد المنفذ من Audit Log.

## تحذير

`BUILD_ON_START=true` يمسح **كل القنوات والتصنيفات والرتب والدعوات** في السيرفر. استخدمه على سيرفر اختبار أول مرة، وخد نسخة احتياطية من الإعدادات والدعوات قبل التشغيل.

## البيانات

- `data/tickets.json` — العدّاد والتذاكر المفتوحة
- `data/ratings.json` — تقييمات العملاء
- `data/transcripts/` — نسخ HTML لكل تذكرة مغلقة

## إعادة التشغيل

كل مرحلة idempotent: لو القناة أو الرتبة موجودة بنفس الاسم بيتم تحديثها بدل تكرارها. لتعديل الأسعار أو الروابط عدّل `src/config/layout.js` فقط.
